# ⚔️ Pemberitahuan Sumpah Sakral: "Departure to the Front Line"
### Aditya Firmansyah & Salsa Nabila Ramadhani

Website pemberitahuan pernikahan personal bertema **Dramatic, Epic & Cinematic**, terinspirasi dari karya legendaris *"Departure to the Front Line"* (Shutsujin - Naruto Shippuden OST karya Yasuharu Takanashi).

---

## 🎵 Petunjuk Menaruh File Musik (Departure to the Front Line)

Website ini telah disetting untuk otomatis memutar file MP3 lagu tersebut.
Cukup lakukan langkah mudah ini:

1. Unduh / siapkan file MP3 lagu **"Departure to the Front Line"** (Shutsujin).
2. Beri nama file tersebut: **`bgm.mp3`**
3. Letakkan file tersebut di dalam folder **`assets/`** di folder website ini (`assets/bgm.mp3`).
4. Selesai! Saat website dibuka dan tombol **"SAKSIKAN IKRAR PERNIKAHAN"** ditekan, lagu akan otomatis mengalun megah mengiringi setiap babak cerita.

*(Catatan: Jika file belum diletakkan, sistem Web Audio bawaan di browser secara otomatis tetap menghasilkan efek suara dentuman drum sinematik & irama pertempuran agar website tetap dramatis).*

## 🚀 Panduan Publish ke GitHub Pages (Gratis & Cepat)

1. Buka [github.com/new](https://github.com/new) dan buat repository baru (pilih **Public**), misalnya `ikrar-aditya-salsa`.
2. Klik tombol **Add file** > **Upload files**.
3. Tarik (*drag & drop*) seluruh isi folder ini ke browser:
   - 📁 **`assets/`** (berisi `aditya.jpg`, `salsa.jpg`, dan `bgm.mp3`)
   - 📄 **`index.html`**
   - 📄 **`style.css`**
   - 📄 **`script.js`**
   - 📄 **`guests.js`**
   - 📄 **`README.md`**
4. Klik **Commit changes**.
5. Buka tab **Settings** > **Pages** di repository GitHub Anda:
   - Pilih **Branch: main** dan **folder: /(root)**, lalu klik **Save**.
6. Dalam 1–2 menit, website dramatis Anda akan aktif di link:
   `https://USERNAME_ANDA.github.io/NAMA_REPOSITORY/`
